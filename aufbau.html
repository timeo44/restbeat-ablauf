wie diese seite gebaut ist

drei werkzeuge, ein weg: claude schreibt, github speichert, netlify stellt online. kein server, kein build.

1
claudeschreibt index.html
2
githubtimeo44/restbeat-ablauf
3
netlifydeployt automatisch
4
browserrestbeat-ablauf.netlify.app

die drei teile

claude
schreibt und ändert die seite im chat. html, css und javascript stecken in einer datei, ohne framework.
github
speichert jede version im repo timeo44/restbeat-ablauf, branch main. so lässt sich jede änderung nachvollziehen und zurückholen.
netlify
ist mit dem repo verknüpft. bei jedem push auf main holt es die dateien und stellt sie in etwa einer minute online.

so läuft eine änderung

  1. du sagst claude, was anders sein soll.
  2. claude ändert index.html und prüft das script.
  3. claude macht einen commit und einen push auf github.
  4. netlify merkt den push und veröffentlicht die neue version. fertig, ohne dass du etwas klicken musst.
